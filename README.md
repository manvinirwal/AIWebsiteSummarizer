
# AI Website Summarizer & AI Arena

This project contains two AI-powered applications built using Large Language Models (LLMs).

## Applications

### 1. Website Summarizer (`app.py`)

An AI-powered application that extracts content from any publicly accessible website and generates concise summaries.

#### Features

- Extracts webpage content using a custom web scraper.
- Cleans and preprocesses webpage text.
- Generates high-quality summaries using Large Language Models.
- Interactive user interface built with **Gradio**.

#### Workflow

```
Website URL
      │
      ▼
Web Scraper
      │
      ▼
Text Cleaning
      │
      ▼
Custom Summarizer
      │
      ▼
LLM
      │
      ▼
Summary
```

---

### 2. AI Arena (`arena_app.py`)

A side-by-side comparison tool that allows users to compare responses generated by two different Large Language Models.

#### Models

- **Groq**
  - `llama-3.3-70b-versatile`

- **Google Gemini**
  - `gemini-3.5-flash`

Users can enter a prompt once and receive responses from both models simultaneously, making it easy to compare their reasoning, style, and quality.

#### Workflow

```
User Prompt
      │
      ├──────────────► Llama 3.3 (Groq)
      │
      └──────────────► Gemini 3.5 Flash
                    │
                    ▼
        Side-by-Side Responses
```

## Installation

Clone the repository

```bash
git clone https://github.com/<username>/AI-Website-Summarizer.git

cd AI-Website-Summarizer
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GROQ_API_KEY=your_groq_api_key
GEMINI_API_KEY=your_gemini_api_key
```
